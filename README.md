How to Run the App

Download the project from GitHub.

Open the project folder in VS Code.

Make sure Python is installed.

Open the terminal and install the required library:

pip install -r requirements.txt

Run the program:

python main.py

Type start to open the app.

Choose an option from the menu to test the program.
