## How to Run the App

1. Download the project from GitHub by clicking Code and Download ZIP.
2. Extract the ZIP file.
3. Make sure Python is installed on your computer.
4. Open the extracted project folder.
5. Double-click start.bat.
6. Type start to open the app.
7. Choose an option from the menu to test the program.

The required library will be installed automatically.

No VS Code or manual terminal commands are required.
